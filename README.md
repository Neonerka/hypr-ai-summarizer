# AI Assist — локальный ИИ-ассистент для Hyprland

Выпадающее окно с ИИ-помощником поверх рабочего стола.  
Три режима работы: поиск по буферу обмена, свободный поиск, ответ по документации.

## Как это выглядит

- `Super+Shift+A` — открыть окно. Если в буфере есть текст — сразу идёт поиск + ответ
- Если буфер пуст — открывается пустое окно в режиме «Поиск»
- Переключение между режимами радио-кнопками: **Буфер** / **Поиск** / **Доки**
- В режиме «Доки» появляется дополнительное поле для источников документации
- Можно задавать уточняющие вопросы — контекст разговора сохраняется
- `Escape` — закрыть окно

## Режимы работы

| Режим | Поле запроса | Что происходит |
|---|---|---|
| **Буфер** | авто-заполняется из буфера обмена (read-only) | Поиск в DuckDuckGo + ответ |
| **Поиск** | вводишь свой запрос | Поиск в DuckDuckGo + ответ |
| **Доки** | вводишь запрос + источники снизу | Загрузка документации + ответ (без поиска) |

### Источники документации (режим «Доки» и команда `/doc`)

Каждая строка — отдельный источник. Поддерживаются форматы:

| Формат | Пример | Описание |
|---|---|---|
| `https://...` | `https://wiki.archlinux.org/title/Hyprland` | HTML-страница |
| `man:name` | `man:hyprctl` | Man-страница |
| `arch:page` | `arch:Hyprland` | Arch Wiki (сокращение) |
| `gh:user/repo` | `gh:hyprwm/Hyprland` | GitHub README |
| `file:path` | `file:~/docs/guide.md` | Локальный файл |
| `/path` | `/home/user/docs/guide.md` | Локальный файл |

### Команда `/doc` в follow-up

В поле `>>>` можно написать `/doc <источник>`, чтобы загрузить документацию по ходу диалога.

## Зависимости

- `wl-clipboard` — чтение буфера обмена
- `python-requests` — http-запросы к Ollama
- `duckduckgo_search` (pip) — поиск в DuckDuckGo
- `Ollama` с любой моделью

## Установка

Скрипт `install.sh` сделает всё автоматически.  
По умолчанию ставится модель `qwen2.5:3b-instruct`, но можно указать другую:

```bash
bash install.sh                     # qwen2.5:3b-instruct
bash install.sh llama3.2:1b        # другая модель
bash install.sh "mistral:7b"       # или любая другая
```

## Выбор модели

Модель `qwen2.5-coder:3b-instruct` — **личная преференция автора.**  
Она подходит не на каждую систему и не для каждой задачи.  
Скрипт должен быть вариативным — просто замени `MODEL` в `ai-assist.py`:

```python
MODEL = 'qwen2.5-coder:3b-instruct'   # замени на свою
```

Либо передай через аргумент (не реализовано — правь в файле).  
Перед этим скачай новую модель: `ollama pull <имя_модели>`.

## Файлы

| Файл | Назначение |
|---|---|
| `ai-assist.py` | GTK-окно: 3 режима, стриминг Ollama, загрузка документации |
| `toggle-ai-assist.sh` | Запуск через хоткеи, адаптивный размер под монитор |

## Конфигурация Hyprland

### Window rules (`~/.config/hypr/hyprland/rules.conf`)
```conf
windowrule = float true, match:class ai-assist
windowrule = dim_around true, match:class ai-assist
windowrule = animation slide, match:class ai-assist
```

### Клавиша (`~/.config/hypr/hyprland/keybinds.conf`)
```conf
bind = Super+Shift, A, exec, /home/neonerka/scripts/toggle-ai-assist.sh
```

## Как работает

1. **ai-assist.py** — GTK-окно (безрамочное, белый полупрозрачный фон, JetBrains Mono)
   - Три режима: Буфер / Поиск / Доки — переключаются радио-кнопками
   - **Буфер**: читает CLIPBOARD, если пусто — PRIMARY
   - **Поиск**: ручной ввод запроса
   - **Доки**: запрос + источники документации (URL, man, файлы)
   - Ищет в DuckDuckGo (10 результатов) — только в режимах Буфер/Поиск
   - Отправляет запрос + контекст в Ollama (`localhost:11434`, `num_ctx=32768`)
   - Стримит ответ в текстовое поле
   - После ответа — `>>>` для уточняющих вопросов (без повторного поиска)
   - Команда `/doc <источник>` в `>>>` загружает доку и отвечает по ней

2. **toggle-ai-assist.sh**:
   - Если в буфере есть текст — убивает старое окно и запускает новое в режиме Буфер
   - Если буфер пуст — закрывает окно или открывает пустое в режиме Поиск
   - Размер окна: 45% × 35% от разрешения активного монитора
   - Позиция: в верхней части экрана по центру

3. **Аргументы ai-assist.py**:
   ```
   --width <px>      ширина окна
   --height <px>     высота окна
   --query <text>    запрос (режим Буфер, автостарт)
   --doc <source>    источник документации (режим Доки, можно несколько)
   ```

## Особенности

- Весь трафик локальный — в интернет уходит только поиск DuckDuckGo
- Промпт на русском, ответы всегда на русском
- В конце ответа — блок «Общая сводка»
- Окно фиксированного размера, скролл без скроллбара
- Модель предзагружается при старте системы (через `ollama-preload.service`)
